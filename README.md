# Food Delivery App

## Objective: 
We have to make a project with React and Backend for food service application. Our user can search food items, order and cancel it within a limited time. We will show payment options, food tracking and payment status. We will apply authorisation for ordering and tracking items. This project will be made such that it will be maintainable easily.

## Requirements:
- A user can login and logout from the application.
- User can search items without login.
- For ordering, tracking and payment items, user will  have to login.
- We will have provide areas such that a user can    order items for other peoples too.
- App will provide higher rated restaurants for new          users.
- User will have various choices among restaurants.
- We will provide pagination.
- User can cancel there order within 30 min.
- User can provide tips to restaurants.
- User can review after the order is reached its destination. Review will have star rating and a comment.
- User will have discounts and coupons if its available.
- User will have their previous orders in history.
- App will have FAQs.
